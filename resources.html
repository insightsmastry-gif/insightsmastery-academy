Served straight from the repository

There is no upload step and no CDN in front of these files. Each download points at the real pdfs/ folder in the repository, so the byte size and “updated” date you see above are the file’s actual size and last commit time.

Adding a handbook is a git operation: drop the PDF into pdfs/, push, and the build regenerates content/manifest.json — the new file appears in this list, with its category, tags and size, on the next deploy. No code change, no hard-coded filenames anywhere.
