1. How to Use This Handbook

This handbook is written as if an experienced teacher is sitting beside you, building a real report with you click by click. You do not need any programming background. Bookmarks need no DAX at all — only a clear idea of what state you want to save and what should change when a user clicks.

Recommended Learning Path

  1. Read Chapters 3–6 in order. They explain what a bookmark saves and the four option switches — the part most people get wrong.
  2. Build the practice report in Chapter 2 in Power BI Desktop before starting the patterns.
  3. Build every pattern in Chapter 10 yourself. Click the bookmark, then check it against the Expected behaviour line.
  4. Use the Troubleshooting chapter whenever a bookmark does something unexpected.
  5. Finish with the Mini Project and the practice exercises.

Teaching Pattern Used Throughout

For every feature and pattern we follow this exact pattern:

WHAT → WHY → WHERE TO CLICK → OPTION SETTINGS → STEP BY STEP → EXPECTED BEHAVIOUR → COMMON MISTAKE → PRACTICE

How to read an option table

Every pattern ends with a small table of the four bookmark options. On means the check mark is ticked, Off means it is cleared, Either means it does not matter.

3. What Is a Bookmark?

3.1 Simple Meaning

A bookmark is a saved snapshot of the state of a report page. When someone selects it, Power BI puts the page back into exactly that state.

Camera Analogy

Think of a bookmark as a photograph of your report settings — not of the data. When you select the bookmark, Power BI rearranges the settings to match the photo, but the numbers are always today's numbers from the model.

3.2 Why Do We Need Bookmarks?

  • Interactivity without code — show or hide visuals when a button is clicked (toggles, pop-ups, panels, tabs).
  • Saved views — jump straight to 'North Electronics this month' without re-selecting slicers.
  • Storytelling — step through insights one by one like a slide show.
  • Reset — give users a one-click way back to the default view.
  • Personal views — readers in the Power BI service can save their own filtered views.

3.3 What a Bookmark Saves

According to Microsoft's documentation, a report bookmark stores these elements:

3.4 What a Bookmark Does NOT Save

Not savedWhat this means for you
Position and size of visualsMove a visual after creating the bookmark, and the bookmark will not move it back.
Formatting (colours, fonts, titles)Formatting belongs to the visual, not to the bookmark.
The data itselfA bookmark stores settings. After a refresh it shows the new numbers.
Visuals added after the bookmarkA new visual is not part of old bookmarks until you select the bookmark and choose Update.
Slicers added after the bookmarkAdding a slicer to a page that already has bookmarks clears that slicer when those bookmarks are applied.

4. The Three Panes You Will Use

Bookmark work happens in three panes. Open all three before you start: in Power BI Desktop, select the View tab and turn on Bookmarks and Selection. The Format pane opens when you select a button.

4.1 The Bookmarks Pane

ControlWhat it does
AddCreates a bookmark from the current state of the page, with a generic name such as Bookmark 1.
ViewStarts a slide show of bookmarks in their pane order (Chapter 5).
More options (…)Rename, Update, Delete, Group, Ungroup, and the option check marks: Data, Display, Current page, All visuals, Selected visuals.
Drag and dropChanges the order. A yellow bar shows where the bookmark will land.
Ctrl + clickSelects several bookmarks, for example to group them.

4.2 The Selection Pane

The Selection pane lists every object on the current page — visuals, shapes, buttons, images, text boxes and groups.

ControlWhat it does
Eye iconShows or hides the object. Visibility is what the Display option of a bookmark saves.
Double-click the nameRenames the object. Clear names make bookmark work far easier.
Layer orderObjects higher in the list sit on top of objects lower down. Pop-ups and panels must be at the top.
Tab orderThe order keyboard users move through objects. Keep buttons next to what they control.
Group (Ctrl + click, then right-click → Group)Treat several objects as one — hide or show a whole panel with one click.
Remember

Hidden slicers still filter the page. You can hide a slicer and still let a bookmark set its value — a technique used in several patterns.

4.3 The Format Button Pane (Action)

Any button, shape or image can trigger a bookmark. Select the object, open Format → Action, turn Action On, set Type = Bookmark, and choose the bookmark.

Desktop tip

In Power BI Desktop, hold Ctrl and click a button to test it. In the Power BI service a normal click works.

5. Creating and Managing Bookmarks

5.1 Create Your First Bookmark — Desktop

  1. Open the Overview page. Set the Region slicer to North.
  2. On the View tab select Bookmarks to open the pane.
  3. Select Add. Power BI creates Bookmark 1.
  4. Select More options (…) → Rename and type North View.
  5. Clear the Region slicer. Total Sales returns to 276,000.
  6. Select North View in the Bookmarks pane.

Expected behaviour: the Region slicer is set to North again and Total Sales shows 131,000.

5.2 Create a Bookmark — Power BI Service

  1. Open the report and select Edit.
  2. Select View → Bookmarks pane.
  3. Arrange the page, then select Add.
  4. Save the report so the bookmark is kept.

You need edit permission on the report to create report bookmarks. Without it you can create personal bookmarks only (Chapter 11).

5.3 Rename, Update, Delete

ActionWhen to use itWatch out
RenameAlways — give every bookmark a meaningful nameButton labels in a bookmark navigator follow the bookmark name
UpdateAfter you change what the bookmark should saveSelect the bookmark first, change the page, then choose Update
DeleteThe bookmark is no longer usedButtons pointing to it stop working — check actions first
The Update workflow

1. Select the bookmark so the page is in its state. 2. Make your change (slicer, visibility, sort). 3. More options (…) → Update. If you skip step 1, you overwrite the bookmark with the state of a different bookmark.

5.4 Reordering Bookmarks

Drag and drop bookmarks in the pane. Order matters for the View slide show and for the button order in a bookmark navigator.

5.5 Bookmarks as a Slide Show (View)

  1. Order the bookmarks in the sequence of your story.
  2. In the Bookmarks pane select View.
  3. A caption bar appears at the bottom of the canvas with the bookmark name and arrows.
  4. Use the arrows to step through; select Exit to finish.

If the selected bookmark is inside a group, View plays only that group. If it is at the top level, View plays every bookmark in the report. Slide shows work in Desktop and in the service, in both Edit and Reading view.

6. The Four Bookmark Options — Deep Dive

Every report bookmark has check marks under More options (…). They decide which parts of the saved state are restored. Understanding them is the single most important bookmark skill.

OptionRestoresDefault
DataFilters, slicers, cross-highlight selection, sort order, drill locationOn
DisplayVisibility (Selection pane eye icons) and Spotlight / focus modeOn
Current pageNavigates to the page the bookmark was created onOn
All visuals / Selected visualsWhich objects the Data and Display settings apply toAll visuals

6.1 Data

What

When Data is on, selecting the bookmark re-applies the filters and slicers that were active when it was created or last updated.

When to turn it OFF

Turn Data off for bookmarks that only switch views — show a table instead of a chart, open a panel, show help. Otherwise every click silently resets the user's slicers.

ScenarioUser has selectedBookmark 'Show Table' clickedData OnData Off
Chart ↔ Table toggleRegion = SouthTable appearsSlicer jumps back to the saved state (e.g. All) — user loses SouthSlicer stays on South — correct

When to keep it ON

  • Preset views: 'North Electronics'
  • Reset / Clear filters bookmarks
  • Storytelling slides that must show specific data

6.2 Display

When Display is on, the bookmark restores which objects are visible or hidden, and whether any visual is in Spotlight or focus mode. Turn it off for bookmarks that should change only filters and leave the layout alone — for example a 'Top Customers' filter bookmark on a page with an open panel.

6.3 Current page

When Current page is on, selecting the bookmark takes the user to the page it was created on. When it is off, the bookmark applies its settings to whichever page is open.

Current pageBookmark created on Overview, clicked while on Region Detail
OnUser is moved to Overview, then the saved state is applied
OffUser stays on Region Detail; the saved filters are applied to Region Detail
Use case for Current page = Off

A 'Clear Region filter' bookmark shared by several pages — each page gets the same reset without jumping.

6.4 All Visuals vs Selected Visuals

By default a bookmark affects all visuals on the page. With Selected visuals, it affects only the objects that were selected (Ctrl + click on canvas or in the Selection pane) when you created or updated it. Every other object is left untouched.

How to create a Selected visuals bookmark

  1. Set the visibility of the objects you want to control.
  2. Ctrl + click those objects in the Selection pane (e.g. Chart – Sales by Region and Table – Customer Detail).
  3. Add the bookmark (or Update an existing one) while they are still selected.
  4. More options (…) → select Selected visuals.
Why Selected visuals matters

Two independent toggles on one page — a chart/table toggle and a filter panel — only work if each bookmark touches only its own objects. With All visuals, opening the panel would also reset the chart/table choice.

7. The Selection Pane — Visibility Mastery

Most interactive bookmark designs are really visibility designs. The Selection pane is where you control them.

7.1 Naming Objects

Default names such as Clustered bar chart and Shape 7 make bookmark work impossible on a busy page. Use a prefix convention:

PrefixObjectExample
Card –KPI cardCard – Total Sales
Chart –Chart visualChart – Sales by Region
Table –Table or matrixTable – Customer Detail
Slicer –SlicerSlicer – Region
Btn –Button, shape or image with an actionBtn – Show Table
Grp –GroupGrp – Filter Panel
Bg –Background shapeBg – Panel Background

7.2 Show, Hide and Update

  1. Click the eye icon next to an object to hide it; click again to show it.
  2. Select the bookmark that should remember this visibility.
  3. Set the eye icons as you want them for that bookmark.
  4. More options (…) → Update.
Important

Changing visibility in the Selection pane does not change any bookmark by itself. When you next select a bookmark, visibility snaps back to what that bookmark saved. Always Update after changing visibility.

7.3 Grouping

Ctrl + click several objects in the Selection pane, right-click, and choose Group. Hiding the group hides every member. Groups keep panels and pop-ups tidy: one eye icon, one Selected visual.

7.4 Layer Order

Objects higher in the Selection pane are drawn on top. A pop-up or slide-in panel must sit above the visuals it covers, and its close button must sit above the pop-up background — otherwise the button cannot be clicked.

7.5 Tab Order

The Selection pane also has a Tab order view. Keep each button next to the visual it controls, so keyboard and screen-reader users move straight from the button to the content.

7.6 Spotlight and Focus Mode

Select a visual's More options (…) → Spotlight to fade every other visual. A bookmark with Display on remembers the Spotlight, which is ideal for story slides that draw the eye to one chart.

8. Buttons and Navigators

8.1 Button Basics

  1. Insert → Buttons and pick a style (Blank, Back, Information, Bookmark, etc.).
  2. Format → Button text: type a clear label, e.g. Show Table.
  3. Format → Action: turn it on, Type = Bookmark, choose the bookmark.
  4. Format → Tooltip: explain what happens when the button is clicked.
  5. Ctrl + click (Desktop) to test.

Button states

StateWhen it showsTip
DefaultNormal stateUse the brand colour
On hoverMouse over the buttonSlightly darker fill signals it is clickable
On pressWhile clickingBrief visual feedback
DisabledAction cannot runUsed by drillthrough buttons with no selection

8.2 Bookmark Navigator

A bookmark navigator is a ready-made set of buttons, one per bookmark, that stays in sync with the Bookmarks pane: labels follow bookmark names, order follows pane order, and the selected button shows the last selected bookmark.

  1. Create the bookmarks and put them in a bookmark group (e.g. Grp – View Tabs).
  2. Insert → Buttons → Navigator → Bookmark navigator.
  3. Format navigator → Bookmarks → choose the group so only its bookmarks appear.
  4. Style the Default, Hover and Selected states; set orientation (horizontal or vertical).

8.3 Page Navigator

Insert → Buttons → Navigator → Page navigator creates one button per page and updates automatically when pages are added, renamed or hidden. Use it for menus; use bookmarks for changes within a page.

Accessibility guidance (Microsoft)

Give the navigator meaningful alt text naming what it changes (e.g. 'Customer detail view selector'). Place bookmark buttons close to the content they modify, and avoid unrelated focusable objects between them.

Two navigators on one page

A report has only one active bookmark at a time. If two navigators control overlapping settings, the highlighted button may not match what is on screen. Make each group control completely separate objects and settings. Also note the navigator's selected state is not reflected in exports.

9. Bookmark Groups

9.1 Create a Group

  1. Ctrl + click the bookmarks to group.
  2. More options (…) → Group. Power BI names it Group 1.
  3. More options (…) next to the group → Rename, e.g. Overview – Toggles.

9.2 Groups in View Mode

If the selected bookmark is in a group when you start View, only that group is played. If a top-level bookmark is selected, all bookmarks in the report are played.

9.3 Ungroup and Remove One Bookmark

Ungroup on any member removes the whole group (the bookmarks remain). To remove only one bookmark from a group, ungroup, then Ctrl + click the ones you want and Group again.

9.4 A Recommended Structure

GroupBookmarksUsed by
Story – Q1 ReviewStory 1 – Total picture, Story 2 – North leads, Story 3 – Laptops drive salesView slide show
Overview – View TabsTab – Chart, Tab – Table, Tab – MatrixBookmark navigator
Overview – PanelsPanel – Open, Panel – CloseFilter panel buttons

Naming convention

Area – Purpose for groups and Purpose – State for bookmarks: Panel – Open, Panel – Close, Tab – Table. Sorted names read like a map of the report's interactivity.

10. Bookmark Patterns — Step by Step

This is the largest chapter. Each pattern is a real report feature. Build them in order on the practice report — later patterns reuse objects from earlier ones.

10.1 Pattern 1 — Reset All Filters

Why: users apply several slicers and cannot find their way back. One button restores the clean default view.

  1. Clear every slicer and Filters-pane filter on the Overview page.
  2. Add a bookmark and name it Reset – Overview.
  3. Set the options below.
  4. Insert a Reset button (Insert → Buttons → Reset). Action: Bookmark → Reset – Overview.
  5. Test: set Region = North (Total Sales 131,000), then Ctrl + click Reset.
DataDisplayCurrent pageApplies to
OnOffOnAll visuals

Expected behaviour: every slicer clears and Total Sales returns to 276,000; any open panel stays as it was because Display is off.

Alternative without a bookmark

The Clear all slicers button action clears every slicer on the page with no bookmark to maintain. Use the bookmark when you also need to reset Filters-pane filters, sort order or drill.

10.2 Pattern 2 — Chart ↔ Table Toggle

Figure 10.1 — Two bookmarks show one visual at a time in the same space

  1. Place the chart and the table in exactly the same position and size.
  2. Selection pane: show the chart, hide the table. Ctrl + click both in the Selection pane. Add bookmark View – Chart.
  3. Show the table, hide the chart. Keep both selected. Add bookmark View – Table.
  4. For both bookmarks set the options below.
  5. Add two buttons: Btn – Show Chart → View – Chart, Btn – Show Table → View – Table.
DataDisplayCurrent pageApplies to
OffOnOnSelected visuals

Expected behaviour: set Region = South, then click Show Table. The table appears with South data only; the slicer stays on South.

Common mistake

Leaving Data on. The toggle then resets the Region slicer to whatever it was when you created the bookmark, and users think the report is broken.

10.3 Pattern 3 — Slide-in Filter Panel

Figure 10.2 — The filter panel slides over the page and closes with an X button

  1. Draw a rectangle Bg – Panel Background. Place Slicer – Region, Slicer – Category and a small Btn – Close Panel on it.
  2. Group them: Grp – Filter Panel. Move the group to the top of the Selection pane.
  3. Show the group; select it; add bookmark Panel – Open.
  4. Hide the group; keep it selected; add bookmark Panel – Close.
  5. Options below for both. Btn – Filters → Panel – Open; Btn – Close Panel → Panel – Close.
DataDisplayCurrent pageApplies to
OffOnOnSelected visuals (the group)

Expected behaviour: the panel opens and closes; slicer values chosen inside the panel keep filtering the page after it closes.

Hidden slicers keep filtering, so users should see which filters are active. Add a card or text showing the current selection, e.g. a measure Selected Region = SELECTEDVALUE(Sales[Region], "All regions").

10.4 Pattern 4 — Help / Information Pop-up

  1. Build a pop-up: a rectangle with a text box explaining the page, plus Btn – Close Help. Group as Grp – Help, top of the Selection pane.
  2. Bookmarks Help – Open (group visible) and Help – Close (group hidden), both with the group selected.
  3. Insert an Information button (the 'i' icon) → Help – Open. Btn – Close Help → Help – Close.
DataDisplayCurrent pageApplies to
OffOnOnSelected visuals (the group)

Expected behaviour: the help box covers the page and closes without changing any filter.

Tip

Add a semi-transparent full-page rectangle behind the pop-up (transparency 40–60%). It dims the report and stops users clicking visuals behind it.

10.5 Pattern 5 — Tabs Inside a Page with a Bookmark Navigator

  1. Place three visuals in the same area: Chart – Sales by Region, Table – Customer Detail, Matrix – Region × Category.
  2. Create Tab – Chart, Tab – Table, Tab – Matrix, each showing one of the three, with all three selected.
  3. Group them: Overview – View Tabs.
  4. Insert → Buttons → Navigator → Bookmark navigator; Format → Bookmarks → Group = Overview – View Tabs.
  5. Style the Selected state (brand fill, white text) so the active tab is obvious.

11. Personal Bookmarks in the Power BI Service

Report readers who cannot edit a report can still save their own views. These personal bookmarks are visible only to the person who created them.

11.1 Create a Personal Bookmark

  1. Open the report in the Power BI service and set filters, slicers and selections as you like.
  2. Select the Bookmarks icon → Show more bookmarks → Personal bookmarks → Add.
  3. Type a name. Tick Make default if this view should open every time.
  4. Select Save. Use More options (…) to Update, Make default, Rename or Delete.

11.2 What a Personal Bookmark Captures

The current page, filters, slicers (including slicer type), visual selection state, sort order and drill location. It does not control visibility — that needs a report bookmark.

11.3 Limits and Behaviour

RuleDetail

Maximum across all reports2,000 personal bookmarks
ExpiryPersonal bookmarks expire after six months
When you can add or updateOnly while viewing a report
GroupingPersonal bookmarks cannot be grouped or rearranged, except choosing the default
Mobile appsReport and personal bookmarks can be used in the iOS and Android apps, but not created there

Teacher Tip

Show your business users the Make default option. A manager who always looks at North Electronics can open the report straight into that view without asking you for a new page.

12. Bookmarks vs Other Features

Bookmarks are powerful, but each bookmark is something to maintain. Choose the simplest feature that does the job.

NeedBest featureWhy not bookmarks?
Switch the measure in one chartField parametersOne visual instead of several hidden copies
Move between pagesPage navigator / Page navigation actionUpdates automatically as pages change
Show details for a selected itemDrillthrough pagePasses the selected item's filter automatically
Extra detail on hoverReport page tooltipNo click needed
Same slicer value on every pageSync slicersKeeps pages consistent without bookmarks
Clear slicersClear all slicers button actionNo bookmark to update when slicers change
Readers saving their own viewsPersonal bookmarksReaders cannot create report bookmarks
Show/hide, panels, pop-ups, storiesBookmarksThis is where bookmarks shine

12.1 Best Practices

  • Name every object and every bookmark before you create the next one.
  • Decide Data / Display / Current page / Selected visuals for each bookmark at creation time — use the decision table in Chapter 6.
  • Prefer Selected visuals for anything that toggles visibility.
  • Group bookmarks by purpose; one group per navigator.
  • After any layout change, click through every bookmark to test it.
  • Keep the number of hidden copies of visuals low; consider field parameters first.
  • Add a visible indicator of active filters when slicers live in a hidden panel.
  • Document the bookmarks on a hidden 'Read me' page for the next report author.

13.1 Five-Step Debug Routine

  1. Open the Bookmarks and Selection panes side by side.
  2. Select the bookmark and watch which eye icons change.
