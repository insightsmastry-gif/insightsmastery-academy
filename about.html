About

A library that maintains itself

InsightsMastery Academy is a folder of Power BI handbooks with a website wrapped around it. Add a file, push it, and the site knows about it — that is the entire product.

How it works

Every page you see is a plain HTML file. There is no CMS, no database and no server-side rendering: a build script walks notes/ and pdfs/, reads each file's title, headings, tags, word count and size, and writes a single content/manifest.json.

The browser fetches that manifest once and renders the library, the search results, the download list and the counters from it. That is why adding a handbook needs no code change — and why the whole site keeps working if JavaScript is slow: the content itself is static HTML.

There is no backend anywhere. Nothing you type is transmitted to a server we control, no analytics script runs, no cookie is set beyond the theme preference stored locally in your own browser. The feedback form below composes an email in your mail app; you stay in control of pressing send.

The stack

Deliberately unfashionable, which is why it will still build in five years.

  • Hand-written HTML, CSS and ES modules — no framework, no bundler, no npm dependencies.
  • A single Node build script that generates content/manifest.json from the content folders.
  • GitHub Actions for the build, GitHub Pages for hosting, plain relative URLs throughout.
  • Design tokens for both themes, motion that respects prefers-reduced-motion, and WCAG 2.1 AA contrast.
  • No trackers, no cookies, no fonts beyond a single Google Fonts stylesheet.
